# WotaGei-Arrangement-Tool 🌟

这是一个专为 **生成公式化光棒编排** 设计的自动化交互脚本。它可以根据中日双行歌词文本，通过简洁的命令行指令快速划分板块、分配拍数，并自动生成带有智能单元格合并逻辑的美观 Excel 编排表。

## 🛠️ 环境配置

本项目建议在 Python 3.10+ 环境下运行。

### 1. 准备环境 (推荐使用 venv)
为了保持系统环境纯净，建议在项目根目录下创建虚拟环境：

```bash
# 创建虚拟环境
python -m venv venv

# 激活虚拟环境 (Windows)
.\venv\Scripts\activate

# 激活虚拟环境 (Linux/WSL/macOS)
source venv/bin/activate
```

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

## 🚀 操作说明

### 第一步：准备歌词

准备一个 `lyrics.txt` 文件，内容必须为 **中日双行交替** 格式：

```text
僕らはやりたいことやるために
我们为了完成心中的祈愿
描き続けた未来　偉大さに
才会对着被描绘得波澜壮阔的未来有所期待
```

### 第二步：运行脚本

```bash
python wota_tool.py
```

### 第三步：执行指令

脚本采用交互式命令行操作，分为 **前奏、歌词流水线、尾奏** 三个阶段。

#### 1. 核心指令映射表
在任何需要输入“类型”的地方，均可使用以下缩写（不区分大小写）：

| 缩写 | 对应板块名称 | 建议使用场景 |
| :--- | :--- | :--- |
| **p** | 前奏 (Pre-chorus/Intro) | 歌曲开头的纯动作部分 |
| **a** | A melo (第一主歌) | 叙事性较强的铺垫段落 |
| **b** | B melo (第二主歌) | 情绪上扬的过渡段落 |
| **c** | C melo (桥段/Bridge) | 副歌后的转折或情绪高潮预热 |
| **r** | 副歌 (Chorus/Refrain) | 歌曲最核心、动作最激烈的段落 |
| **i** | 间奏 (Interlude) | 歌曲中间的纯动作部分 |
| **o** | 尾奏 (Outro) | 歌曲结束后的收尾动作 |

---

#### 2. 交互阶段说明

**A. 前奏/尾奏阶段 (纯动作录入)**
* 直接输入 `p 8`（前奏 8 个八拍）或 `o 4`（尾奏 4 个八拍）。
* 若无对应需求，直接按 **回车** 跳过。

**B. 歌词流水线阶段 (核心编排)**
这是脚本的核心，用于将 txt 歌词分配到对应板块：
* **收纳 (Accumulate)**：直接按 **回车**。当前显示的日文/中文歌词会被存入“暂存区”，并自动展示下一句。
* **打包 (Pack)**：输入 `类型 + 拍数`（如 `r 16`）。脚本会将暂存区的所有歌词连同当前这一句，一起打包进“副歌”板块，并清空暂存区。
* **插入纯间奏**：如果在暂存区为空时输入 `i 4`，脚本会插入一段 4 拍的纯动作间奏，不消耗任何歌词。

**C. 全局撤销 (Undo)**
* **指令**：`u`
* **功能**：基于快照系统，你可以无限次撤销。
    * 如果刚才按错了回车，按 `u` 歌词会退回。
    * 如果刚才打错了包（比如 `r 8` 填成了 `r 80`），按 `u` 会自动“拆解”该板块，歌词全部回到暂存区。

---

#### 💡 进阶技巧：自定义板块
如果你想使用表格外自定义的名称（例如想写 `Sabi` 而不是 `副歌`），直接输入 `Sabi 8` 即可，脚本具有很强的兼容性，会自动识别并填入 Excel。
